Before you start

What this roadmap is (and isn't)

Vibe coding is real. In 2025 Andrej Karpathy coined the term for a workflow where you describe what you want and let AI generate the code — you mostly don't read it, you iterate by feeling. It works. People ship real products this way.

But: the moment something breaks — and it will — you need to be able to read a stack trace, isolate a bug, and fix it. AI is an incredible force multiplier. It is not a substitute for understanding what you shipped.

This roadmap assumes you already know how to start a vibe project. It's about everything after that first "wow, it works" moment: shipping to real users, handling real bugs, and not becoming a passenger in your own codebase.
